# Credential-based attacks — four separate infographics

Each file in `individual/` is a separate 2400 × 3000 RGB PNG, with natively rendered text and diagrams over the same navy/cyan background used by the preceding series.

- 6.1 Kerberoasting — Service-Ticket Evidence
- 6.2 DCSync — Directory Replication Evidence
- 6.3 Pass-the-Hash — Two Hunting Views
- 6.4 LSASS Credential Dumping — Sysmon Event 10

`SOURCES_AND_EVIDENCE_NOTES.md` resolves the bracketed source labels in each graphic. `accessible_text.json` contains the graphic text. `bitmask_checks.json` records the arithmetic behind the LSASS mask examples. `manifest.json` lists image dimensions and SHA-256 checksums.

These are conceptual detection guides, not measured detector performance. The set does not contain a combined infographic or font files.
